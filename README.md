# 🧑‍💼 Apresentação Profissional em C#

Aplicação de console criada para apresentar informações profissionais por meio de um menu interativo.

## Problema

Transformar um currículo estático em uma experiência navegável simples no terminal.

## Solução

O programa organiza informações em seções como apresentação, habilidades, projetos e contato.

## O que eu fiz

- Estruturei um menu de navegação no console
- Organizei informações profissionais em opções separadas
- Apliquei condicionais, loops e organização de fluxo
- Usei C# e .NET em uma aplicação simples de terminal

## Tecnologia

**C# • .NET • Console Application**

## O que este projeto demonstra

Organização de fluxo, lógica de navegação e uso básico de C# em um problema de apresentação de informações.

## Como explicar em entrevista

> "Foi um projeto de fundamentos em C#. Eu queria transformar uma apresentação profissional em uma aplicação de terminal, então criei um menu navegável e organizei o conteúdo por seções. O principal aprendizado foi estruturar fluxo e interação com o usuário."

## Próximo passo
